# Project Name: Website with HTML, CSS, Bootstrap, and SASS

## Overview
This project is the final assignment for an online course provided by **Void Software**. The course covers web development using HTML, CSS and Bootstrap. As part of this course, I built a fully responsive website that includes various sections like a header, introduction, doctor profiles, appointment booking form, and footer.

The goal was to learn how to integrate Bootstrap to create a clean and responsive user interface. The project is structured to be a real-world web application that adapts seamlessly to various screen sizes (mobile, tablet, and desktop).

### Key Features:
- **Responsive Layout:** The website adapts to different screen sizes using Bootstrap's grid system and custom media queries.
- **Modern Design:** Uses the latest web design techniques and styles, including custom fonts, buttons, and hover effects.
- **Smooth Scrolling:** Implemented smooth scrolling between sections of the website.
- **Interactive Components:** Features interactive elements such as the "Contact Us" button and the "Book Now" feature.

## Technologies Used:
- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **SASS (Syntactically Awesome Stylesheets)**

## Features:
- **Header:** Fixed navigation bar that stays at the top of the page.
- **Introduction Section:** An introduction section with a welcome message and some brief text.
- **Doctor Cards:** A section displaying profiles of doctors with hover effects and booking buttons.
- **Appointment Form:** Users can fill in a form to book an appointment.
- **Footer:** A footer section with social media links.
